# 鹈鹕海岸捕鱼记 · Pelican Coastal Ride

一个纯前端的 3D 网页游戏：戴着头盔与墨镜、围着红围巾的鹈鹕在海滨公路上骑车抓鱼。

## 运行

任意静态服务器即可（需支持 ES Module）：

```bash
python3 -m http.server 8123
# 打开 http://localhost:8123/
```

## 玩法

| 按键 | 功能 |
| --- | --- |
| `W` / `↑` | 加速 |
| `S` / `↓` | 刹车 |
| `A` / `←` | 向左变道（靠海，可接住跃出水面的鱼） |
| `D` / `→` | 向右变道 |
| `空格` | 跳跃 |
| `T` | 展翅抬前轮 |
| `C` / `1`-`5` | 切换镜头（追尾 / 电影运镜 / 鹈鹕视角 / 侧视 / 航拍） |
| `B` | 成就面板 |
| `M` | 静音 |

移动端提供触屏按钮。停止操作 4.5 秒后进入自动驾驶，自动变道追鱼。

## 技术要点

- Three.js（已本地化到 `vendor/`，无需外网依赖）
- Gerstner 波浪海面 + 碎浪泡沫着色器、程序化天空穹顶（太阳 / 月亮 / 程序化星空）
- Verlet 质点布料模拟的红围巾
- Web Audio 实时合成：踏板声、随踏频变化的节拍与和声、海浪、风声、夜虫、捕鱼音效
- 按帧率自适应画质（分辨率 / 阴影 / 泛光 / 海面细分 / 布料迭代）
